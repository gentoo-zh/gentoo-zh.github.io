## Gentoo中文社群的源起

Gentoo 中文專案，是中國大陸愛好者進行 Gentoo Linux 交流、討論的一個技術社群。此次 Gentoo 中文社群的建設算是第三次組建。

第一次，2004 年前後，由 LinuxSir 上面的 Gentoo 愛好者發起並維護，為 Gentoo 在中國大陸的推廣做出了貢獻，但最終專案因故中
止（詳見 [1]）。

第二次，2007 年開始，由張樂所發起的第二次 Gentoo 中文文件的翻譯專案。取得的最大成果是將 Gentoo 
手冊全部翻譯為中文，並將其提交到官方，也就是目前我們看到的[官方 Gentoo 中文手冊](https://wiki.gentoo.org/wiki/Handbook:Main_Page/zh-cn)，目前翻譯專案還正常執行（詳見 [2]）。

此次 Gentoo 中文專案的發起，算是第三次了。主要由[清風](http://weibo.com/zhcj)來負責籌建各項事務，最終確定平臺名稱為
"Gentoo 中文社群"。期間得到許多 Gentooers 的大力支援。

## Gentoo中文社群發展目標

對各種中國大陸 Gentoo 相關資源進行有效整合，把 Gentoo 使用者引導到一起交流，給新手解決問題，讓高手交流技術，
提高中國大陸 Gentoo 發行版的普及率，最終達到提高中國大陸 Linux 技術水平、回饋 Gentoo 官方的中長期目標。

## Gentoo中文社群專案管理

* 主站伺服器架設及管理：[清風](http://weibo.com/zhcj)、[比爾蓋子](http://weibo.com/biergaizi)
* 文件翻譯：繼續使用張樂的翻譯平臺，在這裡也非常感謝他為 Gentoo 中文做出的貢獻！
* 論壇管理：清風（暫時），招聘中。。。
* 部落格設計整合、寫作者：各位 Gentoo 愛好者
* 其他專案管理：詳見下面專案，歡迎大家積極參與管理！

## Gentoo中文社群專案列表

* 主站：官方網站的中文鏡像，用來翻譯官方新聞、釋出中國大陸相關新聞，連結各種國內外相關資源。
  - 中國大陸已備案域名：gentoo.org.cn
  - 伺服器：阿里雲 VPS
  - 網站伺服器軟體：Nginx、gorg
* 論壇：進行 Gentoo 學習、技術交流的場所。
* 部落格：整合優秀獨立部落格內容，釋出一些個人製作的教學、技巧。在 GitHub 上共同參與創作，主站同步內容。
* 文件：使用 gentoo-zh.org 上的翻譯平臺。
* overlay 專案：用網站伺服器同步 GitHub 上的 gentoo-zh 到 GitCafe（為什麼？你懂的……暫未完成）。
* 其他：QQ 群、微博、IRC、郵件列表、Google Groups 等，充分利用各種工具，組織大家進行交流。如菜菜博士的 avbot，可以實現 QQ 群與 IRC、XMPP 的互通。
