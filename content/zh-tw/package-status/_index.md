## 收錄範圍 {#scope}

本站發布建置機的整個 `PKGDIR`，包括收錄的 overlay 套件及從原始碼建置的 `::gentoo` 相依套件。發布前移除被 mask、受 `RESTRICT=bindist` 限制或繼承 `linux-mod` 的二進位套件；`acct-group`、`acct-user` 與 `virtual` 不依類別排除。附帶的相依套件不取代 Gentoo 官方 binhost。純文字清單見 [stable](https://distfiles.gentoozh.org/packages.txt) 與 [unstable](https://distfiles.gentoozh.org/packages-unstable.txt)。

## 狀態說明 {#status-help}

套件列表分開顯示公開索引、直接建置清單、目前發布政策與 distfiles 鏡像狀態。同一列可以同時出現多個狀態，因為它們說明不同事實。distfiles 欄顯示索引中的檔案數量。

| 狀態 | 觸發條件與常見原因 |
| --- | --- |
| `已發布` | 公開索引已有該套件，可從本站下載。發布政策欄針對目前 ebuild；已發布產物依其版本與建置時的 USE 通過發布檢查。 |
| `待發布` | 該套件是直接建置目標，但公開索引尚無二進位套件。它可能尚未完成首次建置，也可能在最近一次發布時未成功；該狀態只表示目前沒有公開產物。 |
| `已排除` | 維護清單明確排除該套件。常見原因包括無法建置、缺少支援或需要進一步核對再散布條件；原因欄顯示記錄的具體原因。 |
| `不在此頻道` | 該套件仍在共用收錄清單中，但不符合目前頻道的相依套件或建置條件，因此本頻道不直接建置。另一個頻道仍可能發布該套件。該套件作為其他套件的相依套件建置時，本頻道仍可能有它的二進位套件。 |
| `清單外` | 該套件不是直接建置目標。上游已提供預先編譯內容或建置收益較低時通常不會直接收錄，但仍可能作為相依套件一併發布；套件名含 `-bin` 不會自動決定該狀態。未偵測到常見建置 eclass，或偵測到建置流程但不在建置清單中，也會顯示此狀態；這不是發布限制。 |
| `不提供 binpkg` | 目前 ebuild 的 `RESTRICT` 包含 `bindist`，因此本站不發布該套件的二進位套件。原始碼套件和上游預先編譯套件都可能設定這項限制，常見原因是授權條款、上游發布條款或預先編譯內容的再散布條件不允許本站散布二進位產物；套件名含 `-bin` 本身不是判定依據。distfiles 是否鏡像仍依 `RESTRICT` 中的 `mirror`、`fetch` 與每個 `SRC_URI` 項目分別判定。 |
| `授權限制` | 目前 ebuild 的 `LICENSE` 表達式不屬於本站固定的 `@BINARY-REDISTRIBUTABLE`。授權條款可能允許附帶條件的再散布，但本站不會據此發布二進位套件；該狀態與 `RESTRICT=bindist` 分開判定。 |
| `已移除` | overlay 已移除該套件，但公開索引仍有它的二進位套件，仍可下載。該列不連結到 overlay。 |
| `Distfiles —` | 該套件沒有宣告 distfile、`RESTRICT` 包含 `mirror` 或 `fetch`，或宣告的檔案尚未全部進入鏡像。該狀態不表示二進位套件不可用。 |
| 政策不明 | 無法確定目前 ebuild 是否符合二進位套件發布政策 |
| `無 amd64` | 沒有 amd64 關鍵字 |
| `已遮蔽` | 被 `profiles/package.mask` 遮蔽 |
| `僅 9999` | 僅有 live ebuild，本站不發布二進位套件 |
