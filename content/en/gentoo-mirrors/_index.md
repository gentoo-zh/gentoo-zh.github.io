These mirror Gentoo's official repositories: the ebuild repository, distfiles and the official binary packages. For the gentoo-zh overlay's mirrors, see [Overlay mirrors](/mirrorlist/).

## Mirror overview

Use the distfiles URL in `GENTOO_MIRRORS`; ✓ means tested working. For Git and rsync URLs and configuration, see [Official mirror setup](/gentoo-repo-setup/).

For the full official lists, see [Download mirrors](https://www.gentoo.org/downloads/mirrors/) and [rsync mirrors](https://www.gentoo.org/support/rsync-mirrors/).
