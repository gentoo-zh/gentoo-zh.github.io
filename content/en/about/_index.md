<!-- anchor:welcome-to-the-gentoo-zh-community -->

gentoo-zh maintains an overlay, a download site and community services for Gentoo users, all run by volunteers.

<!-- anchor:what-this-site-is-for -->

The site gathers related resources and brings Gentoo users together: newcomers find a way to solve problems, experienced users exchange know-how, and Gentoo becomes easier to start with.

## Site languages {#language}

The site comes in Simplified Chinese, Traditional Chinese and English, each written separately with no automatic conversion. Simplified and Traditional are two scripts of one language and culture; contributions in either are welcome.

<!-- anchor:why-zh -->

The zh in the name is the ISO 639 language code for Chinese: it identifies a language, not a country or region, while cn is an ISO 3166 country code with a narrower scope. gentoo-zh itself came from the old gentoo-tw and gentoo-china [when the two communities merged](https://code.google.com/archive/p/gentoo-taiwan/issues/2).

<!-- anchor:english -->

The public pages are available in English; some technical articles are not translated. Report translation errors or submit a pull request on [GitHub](https://github.com/gentoo-zh/gentoo-zh.github.io).
