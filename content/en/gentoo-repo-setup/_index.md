The Gentoo ebuild repository contains the ebuilds and metadata Portage uses to resolve and build packages.

<!-- slot:setup -->

## Synchronize the Gentoo ebuild repository with Git {#git-sync}

### Tested working Git sources

| Mirror | Sync URL |
| --- | --- |
| Tsinghua TUNA | `https://mirrors.tuna.tsinghua.edu.cn/git/gentoo-portage.git` |
| USTC | `https://mirrors.ustc.edu.cn/gentoo.git` |
| ZJU | `https://mirrors.zju.edu.cn/git/gentoo-portage.git` |
| NJU | `https://mirrors.nju.edu.cn/git/gentoo-portage.git` |
| BFSU | `https://mirrors.bfsu.edu.cn/git/gentoo-portage.git` |
| SDU | `https://mirrors.sdu.edu.cn/git/gentoo-portage.git` |
| HUST | `https://mirrors.hust.edu.cn/git/gentoo-portage.git` |
| GitHub (overseas) | `https://github.com/gentoo-mirror/gentoo.git` |

Install `eselect-repository`:

```bash
$ sudo emerge --ask app-eselect/eselect-repository
$ sudo eselect repository remove -f gentoo
$ sudo eselect repository add gentoo git https://github.com/gentoo-mirror/gentoo.git
$ sudo emaint sync -r gentoo
```

Remove the current Gentoo ebuild repository configuration and local copy, then add the Git repository from the selected mirror. Mirrors can have different synchronization progress; when changing Git mirrors, consider deleting and adding the repository again.

With CERNET selected, git prints `warning: redirecting to ...`, because CERNET routes the request to the nearest member mirror. The sync itself completes normally.

For manual configuration or changing mirrors, edit the file under `/etc/portage/repos.conf/` that contains the `[gentoo]` section. For a new configuration, create `/etc/portage/repos.conf/gentoo.conf`; configurations generated by `eselect-repository` are stored in `/etc/portage/repos.conf/eselect-repo.conf`.

Complete configuration example:

`/etc/portage/repos.conf/gentoo.conf`:

```ini
[gentoo]
location = /var/db/repos/gentoo
sync-type = git
sync-uri = https://github.com/gentoo-mirror/gentoo.git
auto-sync = yes
```

When switching from rsync to Git for the first time or changing mirrors, remove the existing local repository and synchronize it again:

```bash
$ sudo rm -rf /var/db/repos/gentoo
$ sudo emaint sync -r gentoo
```

See [Portage with Git](https://wiki.gentoo.org/wiki/Portage_with_Git) for configuration details and troubleshooting.

## Synchronize the Gentoo ebuild repository with rsync {#rsync-sync}

{{< callout type="warning" >}}
Most mirrors only offer git / distfiles, not rsync sync. The mirrors below are tested and do list the `gentoo-portage` module.
{{< /callout >}}

| Mirror | Sync URL |
| --- | --- |
| Tsinghua TUNA | `rsync://mirrors.tuna.tsinghua.edu.cn/gentoo-portage` |
| USTC | `rsync://rsync.mirrors.ustc.edu.cn/gentoo-portage` |
| BFSU | `rsync://mirrors.bfsu.edu.cn/gentoo-portage` |
| NCHC (Taiwan) | `rsync://ftp.twaren.net/gentoo-portage` |
| PlanetUnix (Hong Kong) | `rsync://hippocamp.cn.ext.planetunix.net/gentoo-portage` |

Edit `/etc/portage/repos.conf/gentoo.conf` and point `sync-uri` at any of the addresses above:

`/etc/portage/repos.conf/gentoo.conf`:

```ini
[gentoo]
location = /var/db/repos/gentoo
sync-type = rsync
sync-uri = rsync://hippocamp.cn.ext.planetunix.net/gentoo-portage
auto-sync = yes
```

Then run `emaint sync -r gentoo`.
